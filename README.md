# Sistema de Academia


Meu primeiro projeto em Python, criado para colocar em prática o que estou aprendendo sobre programação.

A ideia é fazer um sistema simples de academia onde é possível cadastrar, consultar, listar e remover alunos.


## Funcionalidades

- Cadastrar alunos
- Consultar aluno pelo CPF
- Listar alunos cadastrados
- Remover aluno pelo CPF


## O que aprendi

- Listas e dicionários
- Condições com if e elif
- Laços com while e for
- Uso de break e continue
- Adicionar e remover itens de uma lista
- Buscar informações dentro de uma lista

## Como executar

Execute o arquivo `main.py` com Python.
